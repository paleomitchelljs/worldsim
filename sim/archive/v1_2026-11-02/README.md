# worldsim

Zero-player civilization simulator on `../gis/world.gpkg`.

    ~/.venvs/worldsim/bin/python worldsim.py --peoples peoples_headstart \
        --starts 20 --start-vary 0.1 --seed 91 --years 6400 --vary 0.12 \
        --out runs/terrain_seed91

Documentation: [docs/README.md](docs/README.md). It holds the goals and an
index to everything else.
